# MCleaner

Приложение для магнитолы Geely Monjaro (ECARX, Android 9). Показывает, сколько занято оперативной памяти, накопителя и процессора и кто это занимает. Освобождает память и чистит кэш, не трогая навигацию, музыку и системные приложения машины.

- **Базовый режим** — без настроек. Показывает память и накопитель, кнопка «Ускорить» просит систему выгрузить фоновые приложения, остальные действия открывают системную карточку приложения.
- **Полный режим** — через [Shizuku](https://github.com/RikkaApps/Shizuku) (права ADB, root не нужен). Показывает память по каждому приложению и загрузку процессора. Останавливает приложения, чистит кэш одной кнопкой, умеет замораживать приложения и автоматически ускорять магнитолу после включения.

В интернет приложение ходит только за обновлениями: к GitHub (`api.github.com`, `github.com`). Аналитики и рекламы нет.

## Обновление

Новые версии ставятся из самого приложения. При запуске MCleaner сам проверяет [релизы на GitHub](https://github.com/harms-danil/MonjaroCleaner/releases). Если интернета нет, делает до 5 попыток с паузой 15 секунд и молча продолжает работу. Если вышла новая версия, появится окно со списком изменений и кнопкой «Скачать и установить». Проверить вручную: «Настройки» → «Проверить обновления».

- С Shizuku обновление ставится без вопросов, приложение перезапускается.
- Без Shizuku Android покажет окно установки. В первый раз он попросит разрешить MCleaner установку приложений.
- Обновление ставится, только если подписано тем же ключом, что и установленная версия.
- Скачанные версии лежат в `/sdcard/MCleaner/updates/`, хранятся 5 последних.
- «Настройки» → «Другие версии» — установка любой версии с GitHub или с устройства. Старую версию можно поставить только с Shizuku. Если прошивка не разрешает поставить её поверх, MCleaner переустановится, а Shizuku попросит разрешение заново.

## Резервная копия настроек

Белый список, замороженные приложения, автоускорение и остановка Google-сервисов сохраняются в `/sdcard/MCleaner/settings.json` после каждого изменения. Если MCleaner удалить и поставить заново, настройки вернутся из этого файла (версии 1.2.0 и новее). Для записи нужен доступ ко всем файлам: в полном режиме MCleaner выдаёт его себе сам.

## Установка

Файл `MCleaner-<версия>.apk` — на странице [релизов](https://github.com/harms-danil/MonjaroCleaner/releases/latest). Ставится один раз, дальше приложение обновляется само.

- С ноутбука по ADB:

  ```bash
  adb install -r MCleaner-1.3.0.apk
  ```

- Или с флешки: скопируйте APK и откройте его файловым менеджером на магнитоле.

## Быстрая настройка одним скриптом

Положите `MCleaner-*.apk` и `shizuku-*.apk` рядом с папкой проекта, подключите магнитолу по ADB и запустите:

```bash
./scripts/setup-monjaro.sh            # по USB; или: ./scripts/setup-monjaro.sh <IP магнитолы>
```

Скрипт ставит оба APK, выдаёт MCleaner доступ к статистике и файлам, запускает Shizuku и открывает MCleaner. Руками остаётся одно: MCleaner → «Настройки» → «Запросить разрешение». После полной перезагрузки магнитолы: `./scripts/setup-monjaro.sh --start-only`.

## Включение полного режима (Shizuku) вручную

1. Включите режим разработчика: Настройки → О системе → 7 раз нажмите «Номер сборки». На Monjaro путь может отличаться, иногда нужен инженерный пароль.
2. Установите Shizuku: APK с <https://github.com/RikkaApps/Shizuku/releases>.
3. Запустите Shizuku с ноутбука по ADB (на Android 9 «Беспроводной отладки» нет, она появилась в Android 11):

   ```bash
   adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh
   ```

4. Откройте MCleaner → «Настройки» → «Запросить разрешение» → разрешите.
5. После полной перезагрузки магнитолы Shizuku обычно нужно запустить заново (шаг 3). Если магнитола просто «спала», Shizuku продолжает работать.

В полном режиме MCleaner сам выдаёт себе доступ к статистике использования и ко всем файлам.

## Что никогда не трогается

- Системные приложения и пакеты машины (`com.ecarx.*`, `com.geely.*`).
- Приложения из белого списка. По умолчанию: Яндекс Навигатор, Яндекс Карты, Google Maps, 2ГИС, Яндекс Музыка, Spotify, VK Музыка, Shizuku, DiPlay (оба пакета: `com.shilapi.xcertplay` и `com.shihab.diplay`). Список меняется на вкладке «Приложения».
- Приложение на экране (на любом дисплее), играющее музыку или держащее фоновый сервис (уведомление).
- Google-сервисы останавливаются, только если в настройках включено «Останавливать Google-сервисы» (по умолчанию выключено). Заморозить их нельзя.
- Кэш навигаторов и музыки из белого списка не чистится, чтобы офлайн-карты и треки не пропали.

## Чек-лист проверки в машине

Базовый режим:
- [ ] Приложение открывается в горизонтальной ориентации, текст читается, кнопки удобно нажимать.
- [ ] Видны ОЗУ и накопитель, цифры обновляются раз в 2 секунды.
- [ ] «Ускорить» показывает отчёт с припиской про Shizuku.

Полный режим:
- [ ] Чип «Shizuku активен» на «Обзоре».
- [ ] Процессор показывается в процентах, в блоке «Больше всего памяти» есть приложения.
- [ ] На «Приложениях» у работающих приложений есть ОЗУ, у всех — размер кэша.
- [ ] Включите навигатор с маршрутом и музыку → «Ускорить» → навигатор и музыка продолжают работать.
- [ ] Навигатор, которого нет в белом списке (например, Навител), ведёт по маршруту в фоне за экраном музыки → «Ускорить» → навигатор продолжает вести.
- [ ] Если в отчёте «Ускорить» написано «Не удалось проверить, какие приложения сейчас играют…» — сообщите: проверка занятых приложений на этой прошивке не работает, и приложения не останавливаются.
- [ ] «Очистка» → «Очистить кэш всех приложений» → сообщение «Кэш очищен у N приложений». Если вместо этого появился диалог «Поштучная очистка недоступна», напишите об этом: прошивка не даёт чистить кэш по одному приложению.
- [ ] Заморозьте и разморозьте тестовое приложение (не системное).
- [ ] «Найти мусор» → группы с объёмом → удаление после подтверждения.
- [ ] Выключите Shizuku → появился тост «Shizuku остановлен — базовый режим», приложение не упало.

Автоускорение («Настройки» → «Автоускорение»):
- [ ] Включите. Появилось тихое уведомление «MCleaner следит за пробуждением».
- [ ] Заглушите и заведите машину. Через 30–90 секунд пришло уведомление «MCleaner: автоускорение».
- [ ] Повторное включение в течение 10 минут не вызывает второе ускорение.

## Сборка

Нужны JDK 17+ и Android SDK (platform 37, build-tools 36). В `local.properties` укажите `sdk.dir`.

```bash
./gradlew testDebugUnitTest assembleRelease
```

Ключ подписи релиза — `~/.android/mcleaner-release.jks`, пароли — `~/.android/mcleaner-signing.properties` (вне репозитория). Без этого файла релиз собирается неподписанным.

Устройство кода: `core/` — чистая логика с JVM-тестами (парсеры `dumpsys` и `/proc`, правила «Ускорить», поиск мусора). `privileged/` — Shizuku UserService (процесс от uid shell). `data/`, `domain/` — репозитории и сценарии. `ui/` — Compose. `auto/` — автоускорение. Дизайн и план — в `docs/superpowers/`.
