# Changelog

Все заметные изменения MCleaner. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.2.1] — 2026-11-25

Исправления по итогам проверки на эмуляторе Android 9 (1920×720, как у магнитолы).

### Исправлено
- Вкладка «Приложения» в полном режиме закрывала MCleaner с ошибкой (сортировка по памяти и кэшу, когда у части приложений они неизвестны).
- Заголовки и крупные цифры были почти не видны: тёмный текст на тёмном фоне.
- Android 9: MCleaner и `setup-monjaro.sh` выдавали только разрешение на запись в память, без чтения — из-за этого не работали резервная копия настроек и папка `/sdcard/MCleaner`.
- «Найти мусор» предлагал удалить сохранённые версии самого MCleaner и стандартные папки (`DCIM`, `Music`, `Download` и др.).
- Одна и та же пустая папка кэша показывалась в двух категориях мусора.
- В окне «Добавить в белый список» клавиатура закрывала весь список на экране высотой 720 пикселей.
- В стандартный белый список добавлен DiPlay из сборки geely-fixes (`com.shihab.diplay`).

## [1.2.0] — 2026-11-25

### Добавлено
- Резервная копия настроек в `/sdcard/MCleaner/settings.json`: белый список, замороженные, автоускорение, остановка Google-сервисов. Пишется после каждого изменения и восстанавливается после переустановки MCleaner.
- «Настройки» → «Другие версии»: список версий на устройстве и на GitHub, установка любой из них. Старые версии ставятся через Shizuku: сначала поверх, а если прошивка не разрешает — с переустановкой после предупреждения.
- Скачанные версии хранятся в `/sdcard/MCleaner/updates/`; уже скачанная и целая версия повторно не скачивается, остаются 5 последних.

### Исправлено
- Инструкция по Shizuku и README: магнитола работает на Android 9, где нет «Беспроводной отладки», Shizuku запускается с ноутбука по ADB.

## [1.1.0] — 2026-11-25

### Добавлено
- Обновление из приложения: при запуске MCleaner проверяет релизы на GitHub и предлагает скачать и установить новую версию. Без интернета — до 5 попыток с паузой 15 с, затем молча продолжает работу.
- «Настройки» → версия приложения и кнопка «Проверить обновления».
- Установка обновления через Shizuku без вопросов, без Shizuku — через системное окно установки.

### Изменено
- Приложению выдан доступ в интернет (`INTERNET`) и право устанавливать приложения — только для обновлений с GitHub.

## [1.0.1] — 2026-11-24

### Добавлено
- Редактор белого списка в «Настройках»: список приложений, удаление, добавление с поиском по названию и пакету, сброс к стандартному.
- Выборочное удаление мусора: галочка у каждого файла, у категории — три состояния (всё / часть / ничего), показ «выбрано N из M».
- В инструкции Shizuku ссылку на релизы можно открыть или скопировать, команду ADB — скопировать. Если браузера нет, ссылка копируется сама.
- Скрипт `scripts/setup-monjaro.sh`: установка MCleaner и Shizuku, выдача прав и запуск Shizuku с ноутбука по ADB.

### Изменено
- В «Очистке» выбор идёт по файлам, а не только по целым категориям.

## [1.0.0] — 2026-11-22

Первый выпуск.

- Обзор: оперативная память, накопитель, процессор и приложения, которые занимают больше всего памяти.
- «Ускорить»: останавливает фоновые приложения и чистит кэш, не трогая белый список, системные приложения машины, приложения на экране, играющие музыку и с фоновыми сервисами.
- Вкладка «Приложения»: память и кэш по каждому приложению, остановка, очистка кэша, заморозка.
- «Очистка»: кэш всех приложений, поиск мусора (APK, логи, временные файлы, миниатюры, пустые папки).
- Автоускорение после загрузки и пробуждения магнитолы.
- Базовый режим без настроек и полный режим через Shizuku. Разрешения на интернет нет.
