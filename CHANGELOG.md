# Changelog

Все заметные изменения MCleaner. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.6.0] — 2026-11-25

### Добавлено
- «Работать в фоне и запускаться с магнитолой» (включено по умолчанию): MCleaner стартует вместе с магнитолой и остаётся в памяти, в шторке — кнопка «Ускорить».
- Раздел «О программе»: версия, проверка обновлений, другие версии, лицензии, ссылка на проект.
- Боковое меню стало шире, с полными названиями разделов.
- «Обзор»: до 8 приложений и переключатель «Память / Кэш».
- Под кнопкой «Ускорить» — кого именно остановит сейчас и сколько памяти это даст; «Подробнее» — кого не тронет и почему (белый список, занято, системное).
- «Приложения»: столбец «ЦП» (средняя загрузка за последние минуту-две) и сортировка «По процессору».

### Исправлено
- Остановленное приложение больше не висит в системном списке «Запущенные» — ни после «Остановить», ни после «Ускорить».
- Список приложений и «Обзор» обновляются при возврате из системной карточки, где чистится кэш; у кнопки обновления виден ход загрузки.
- Размер кэша учитывает внешний кэш (`Android/data/<пакет>/cache`): у многих приложений больше не показывается 0.
- После смены сортировки список прокручивается к началу.
- Установка встроенного Shizuku: повторное нажатие или повторный ответ прошивки больше не открывает второе окно установки с ошибкой «Приложение не установлено».

## [1.5.0] — 2026-11-25

### Добавлено
- Автозапуск Shizuku без ноутбука: MCleaner подключается к ADB по сети самой магнитолы (если прошивка его держит) и запускает Shizuku после перезагрузки, при открытии и включении экрана. Кнопки «Проверить ADB по сети» и «Запустить Shizuku сейчас».

### Исправлено (по итогам ревью безопасности и стабильности)
- Обновления и откат: APK хранятся в закрытой папке приложения; перед установкой проверяются пакет, подпись и SHA-256 копии; релизы без SHA-256 отклоняются; откат проверяет файл до удаления приложения; при зависании установщика окно не блокируется, откат не уходит в удаление; откат ниже 1.2.2 недоступен.
- Команды shell: все имена пакетов экранируются; файл настроек на /sdcard проверяется, список замороженных из него не восстанавливается; «Разморозить всё» трогает только реально отключённые приложения.
- «Ускорить» больше не останавливает: приложения со службами специальных возможностей и слушателями уведомлений (кнопки руля, автоматизация), плееры на паузе, все лаунчеры и живые обои. Кэш занятых приложений не чистится; запуск по расписанию кэш не чистит совсем.
- Поиск мусора: не трогает файлы приложений из белого списка и машины в `Android/data`/`Android/media`, свежие (моложе часа) файлы и папки; пустые папки удаляются только если всё ещё пусты.
- Заморозка недоступна для лаунчера, клавиатуры и приложений из белого списка.
- Резервная копия настроек: запись с fsync, повреждённый файл не перезаписывается, а откладывается в `settings.json.bad-…`.
- Уведомление о нехватке памяти — без звука и только если памяти мало дольше минуты.
- Значок «Ускорить»: не чаще раза в минуту.
- История ускорений не зависит от неверных часов магнитолы.
- Падения: нет экрана «Установка неизвестных приложений» в прошивке; ошибка во время «Ускорить».
- `setup-monjaro.sh` больше не запускает `start.sh` из общей памяти.

## [1.4.1] — 2026-11-25

### Добавлено
- «Установить Shizuku»: Shizuku 13.6.0 встроен в MCleaner (лицензия Apache 2.0) и ставится одной кнопкой через системное окно, без интернета.
- «Настройки» → «Разрешения»: что нужно MCleaner, что уже выдано. С Shizuku — «Выдать все» одной кнопкой, без Shizuku — кнопка «Выдать» у каждого пункта открывает нужный системный экран.
- «Настройки» → «Лицензии»: тексты лицензий встроенных компонентов.

### Изменено
- Инструкция по запуску Shizuku: команда работает на свежей установке Shizuku 13 (старая `…/start.sh` — нет), добавлен запуск с Android-телефона без ноутбука.
- `setup-monjaro.sh` можно запускать без папки проекта: если APK нет рядом, он скачивает последние MCleaner и Shizuku с GitHub.

## [1.4.0] — 2026-11-25

### Добавлено
- Значок «Ускорить» на рабочем столе: ускоряет, не открывая MCleaner, результат — во всплывающем сообщении. Тот же пункт есть в меню долгого нажатия на значок MCleaner.
- Виджет «Ускорить» со свободной памятью — там, где лаунчер поддерживает виджеты.
- «Обзор» → «История»: итоги за 7 дней, какие приложения останавливались чаще всего, последние ускорения (вручную, автоматически, по расписанию, со значка, из уведомления).
- «Настройки» → «Ускорять по расписанию»: каждые 15, 30 или 60 минут, пока магнитола включена (нужен Shizuku). Без уведомлений, результат — в истории.
- «Настройки» → «Предупреждать о нехватке памяти»: уведомление с кнопкой «Ускорить», когда свободно меньше 10–25 %, не чаще раза в 10 минут.
- «Настройки» → «Перенос настроек»: экспорт в файл (например, на флешку) и импорт из файла. Без окна выбора файла экспорт сохраняется в `/sdcard/MCleaner/export/`.

### Исправлено
- `setup-monjaro.sh --start-only` теперь всегда перезапускает Shizuku: после сбоя системы процесс Shizuku мог остаться, но без связи с ней, и скрипт ошибочно считал его запущенным.

### Изменено
- Кэш: Android 8+ не даёт чистить внутренний кэш одного приложения никому, кроме системы. Теперь MCleaner поштучно чистит то, что можно, — внешний кэш (`Android/data/<пакет>/cache`) с учётом белого списка — при «Ускорить» и «Очистить кэш всех приложений». Кэш одного приложения: внешний чистится сразу, а для внутреннего открывается системная карточка приложения («Хранилище» → «Очистить кэш»).

## [1.3.0] — 2026-11-25

### Добавлено
- «Настройки» → «Внешний вид»: язык (русский по умолчанию или английский) и тема (как в системе, светлая, тёмная). «Как в системе» следует дневному и ночному режиму магнитолы.
- После обновления MCleaner открывается сам: через Shizuku — сразу после установки, без Shizuku — после системного окна установки.

### Исправлено
- Установка через Shizuku: если система отказала, MCleaner это замечает и переходит к системному окну установки, а не ждёт впустую.

## [1.2.2] — 2026-11-25

### Исправлено
- На Android 9 версия 1.2.0 с Shizuku не могла скачать обновление («Permission denied»): у неё было только разрешение на запись в память. Теперь папка загрузки проверяется на деле, а если в `/sdcard/MCleaner` писать нельзя, обновление скачивается в собственную папку приложения.
- Ошибки загрузки больше не выдаются за «Нет связи с GitHub»: отдельно сообщается, что нет доступа к папке.
- Тихая установка обновления через Shizuku не работала на Android 9: системе запрещено читать файл из общей памяти. Теперь APK перед установкой копируется в `/data/local/tmp`. По той же причине откат «поверх» всегда уходил в переустановку.
- `setup-monjaro.sh --start-only` тоже выдаёт MCleaner права на память — так можно вытащить 1.2.0, застрявшую на обновлении.

## [1.2.1] — 2026-11-25

### Исправлено
- Вкладка «Приложения» в полном режиме закрывала MCleaner с ошибкой (сортировка по памяти и кэшу, когда у части приложений они неизвестны).
- Заголовки и крупные цифры были почти не видны: тёмный текст на тёмном фоне.
- Android 9: MCleaner и `setup-monjaro.sh` выдавали только разрешение на запись в память, без чтения — из-за этого не работали резервная копия настроек и папка `/sdcard/MCleaner`.
- «Найти мусор» предлагал удалить сохранённые версии самого MCleaner и стандартные папки (`DCIM`, `Music`, `Download` и др.).
- Одна и та же пустая папка кэша показывалась в двух категориях мусора.
- В окне «Добавить в белый список» клавиатура закрывала весь список на экране высотой 720 пикселей.
- В стандартный белый список добавлен DiPlay из сборки geely-fixes (`com.shihab.diplay`).

## [1.2.0] — 2026-11-25

### Добавлено
- Резервная копия настроек в `/sdcard/MCleaner/settings.json`: белый список, замороженные, автоускорение, остановка Google-сервисов. Пишется после каждого изменения и восстанавливается после переустановки MCleaner.
- «Настройки» → «Другие версии»: список версий на устройстве и на GitHub, установка любой из них. Старые версии ставятся через Shizuku: сначала поверх, а если прошивка не разрешает — с переустановкой после предупреждения.
- Скачанные версии хранятся в `/sdcard/MCleaner/updates/`; уже скачанная и целая версия повторно не скачивается, остаются 5 последних.

### Исправлено
- Инструкция по Shizuku и README: магнитола работает на Android 9, где нет «Беспроводной отладки», Shizuku запускается с ноутбука по ADB.

## [1.1.0] — 2026-11-25

### Добавлено
- Обновление из приложения: при запуске MCleaner проверяет релизы на GitHub и предлагает скачать и установить новую версию. Без интернета — до 5 попыток с паузой 15 с, затем молча продолжает работу.
- «Настройки» → версия приложения и кнопка «Проверить обновления».
- Установка обновления через Shizuku без вопросов, без Shizuku — через системное окно установки.

### Изменено
- Приложению выдан доступ в интернет (`INTERNET`) и право устанавливать приложения — только для обновлений с GitHub.

## [1.0.1] — 2026-11-24

### Добавлено
- Редактор белого списка в «Настройках»: список приложений, удаление, добавление с поиском по названию и пакету, сброс к стандартному.
- Выборочное удаление мусора: галочка у каждого файла, у категории — три состояния (всё / часть / ничего), показ «выбрано N из M».
- В инструкции Shizuku ссылку на релизы можно открыть или скопировать, команду ADB — скопировать. Если браузера нет, ссылка копируется сама.
- Скрипт `scripts/setup-monjaro.sh`: установка MCleaner и Shizuku, выдача прав и запуск Shizuku с ноутбука по ADB.

### Изменено
- В «Очистке» выбор идёт по файлам, а не только по целым категориям.

## [1.0.0] — 2026-11-22

Первый выпуск.

- Обзор: оперативная память, накопитель, процессор и приложения, которые занимают больше всего памяти.
- «Ускорить»: останавливает фоновые приложения и чистит кэш, не трогая белый список, системные приложения машины, приложения на экране, играющие музыку и с фоновыми сервисами.
- Вкладка «Приложения»: память и кэш по каждому приложению, остановка, очистка кэша, заморозка.
- «Очистка»: кэш всех приложений, поиск мусора (APK, логи, временные файлы, миниатюры, пустые папки).
- Автоускорение после загрузки и пробуждения магнитолы.
- Базовый режим без настроек и полный режим через Shizuku. Разрешения на интернет нет.
