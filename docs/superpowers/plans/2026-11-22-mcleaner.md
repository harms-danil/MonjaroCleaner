# MCleaner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать APK «MCleaner» для магнитолы Geely Monjaro: показывает ОЗУ, накопитель и CPU, а также кто их занимает; освобождает память и чистит кэш через Shizuku, а без Shizuku работает в базовом режиме.

**Architecture:** Один Android-модуль `app`. Чистая логика (парсеры, политика выбора кандидатов, классификатор мусора, гейт автоускорения) — простой Kotlin без Android, покрыт JVM-тестами. Привилегированные операции идут через интерфейс `Privileged`: реализация на Shizuku UserService (процесс от uid shell) и заглушка. UI на Compose: левая навигация и 4 экрана, ViewModel на каждый экран, DI вручную через `AppContainer`.

**Tech Stack:** Kotlin 2.2.10, AGP 9.3.0 (встроенный Kotlin, плагин `org.jetbrains.kotlin.plugin.compose`), Gradle 9.5.0 (wrapper копируется из `../DiPlay-geely-stability`), Compose BOM 2026.02.01 + Material3, Shizuku `dev.rikka.shizuku:api`/`provider` 13.1.5, DataStore Preferences, WorkManager 2.12.0, JUnit 4.13.2.

**Spec:** `docs/superpowers/specs/2026-11-22-monjaro-cleaner-design.md`

## Global Constraints

- Корень проекта: `~/monjaro_dev/MonjaroCleaner`, git-репозиторий (инициализируется в Task 1). Пакет и applicationId — `app.mcleaner`, название в UI — «MCleaner».
- `minSdk = 28`, `compileSdk = 37`, `targetSdk = 35`. Java/Kotlin target 17.
- Нет разрешения `INTERNET`.
- Нужны разрешения: `QUERY_ALL_PACKAGES`, `PACKAGE_USAGE_STATS` (tools:ignore), `KILL_BACKGROUND_PROCESSES`, `MANAGE_EXTERNAL_STORAGE`, `RECEIVE_BOOT_COMPLETED`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_SPECIAL_USE`, `POST_NOTIFICATIONS`.
- Никогда не останавливать и не замораживать: пакеты с `FLAG_SYSTEM`, префиксы `com.ecarx.` и `com.geely.`, само приложение, Shizuku (`moe.shizuku.privileged.api`). Единственное исключение — Google-пакеты (`com.google.android.gms`, `com.google.android.gsf`, `com.android.vending`): их останавливают только при включённой настройке «Останавливать Google-сервисы» (по умолчанию выкл.) и не замораживают никогда.
- Команды с пользователем используют `U` из `am get-current-user`, а не `0`.
- Автоускорение: после загрузки через 90 с, после пробуждения через 30 с, между запусками не меньше 10 мин, по умолчанию выключено.
- UI: только тёмная тема, только landscape (`screenOrientation="sensorLandscape"`), касание от 56 dp, основной текст от 18 sp, весь текст на русском.
- Обзор обновляется каждые 2 с, пока экран виден.
- Keystore релиза лежит вне git: `~/.android/mcleaner-release.jks`. Итоговый APK — `~/monjaro_dev/MCleaner-<versionName>.apk`.
- Сборка: `JAVA_HOME` — JDK из Homebrew, `local.properties` с `sdk.dir=~/Library/Android/sdk` (в `.gitignore`).

## Review Focus

1. Shizuku умирает посреди «Ускорить» (binder dead или exec бросает исключение). Ожидание: операция завершается, в отчёте не остановленные пакеты, приложение не падает, статус переходит в базовый режим. Тест: `BoostUseCaseTest.shizukuDiesMidway_reportsFailures`.
2. Вывод `dumpsys` на прошивке отличается (нет секции, другие отступы, строки с запятыми в числах «123,456K»). Ожидание: парсер возвращает то, что смог разобрать, или пустой список, без исключения. Тесты в `DumpsysMeminfoParserTest`.
3. Автоускорение срабатывает дважды подряд (загрузка и сразу пробуждение). Ожидание: второй запуск пропускается из-за 10-минутного кулдауна. Тест: `AutoBoostGateTest.bootThenWake_withinCooldown_skipsSecond`.
4. Навигатор на переднем плане, а радио вне белого списка играет звук. Ожидание: ни то, ни другое не останавливается. Тест: `BoostPolicyTest.foregroundAndMediaApps_notKilled`.
5. Скан мусора упирается в symlink-цикл или нечитаемую папку. Ожидание: скан не зацикливается и не падает, нечитаемые папки пропускаются. Тест: `JunkScannerTest.symlinkLoop_terminates`.
