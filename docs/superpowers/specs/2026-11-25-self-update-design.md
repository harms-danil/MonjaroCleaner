# MCleaner: обновление из приложения — короткий дизайн

## Зачем
Чтобы не скачивать каждый новый релиз руками и не ставить его через ноутбук или флешку.

## Решения пользователя
- В «Настройках» видна версия приложения и есть кнопка «Проверить обновления».
- При открытии приложения проверка идёт сама. Если интернета нет — до 5 попыток с паузой 15 с, потом молча продолжаем работу.
- Если обновление есть — окно с версией, списком изменений и предложением скачать и установить.
- Приложению разрешён интернет (`INTERNET`), но только к GitHub.
- Установка: через Shizuku — молча; без Shizuku — системное окно установки (в первый раз Android попросит разрешить установку из этого источника).

## Как устроено
- **Источник:** `GET https://api.github.com/repos/harms-danil/MonjaroCleaner/releases/latest`, без токена. Берём `tag_name`, `body`, ассет `MCleaner-*.apk` (`browser_download_url`, `size`).
- **Сравнение версий:** `v1.2.3` против `BuildConfig.VERSION_NAME` по числам; обновление — только если строго новее.
- **Изменения:** из `body` релиза — текст между первой строкой-заголовком и блоком «**Установка:**» (это раздел CHANGELOG, его кладёт `publish-release.sh`).
- **Повторы:** только при сетевой ошибке (нет сети, таймаут). Ответ сервера с ошибкой (например, лимит GitHub) — не повторяем. Таймаут соединения и чтения — 15 с.
- **Скачивание:** в `Android/data/app.mcleaner/files/update/` (shell через Shizuku может читать этот путь). Проверяем размер и, если в описании есть, SHA-256.
- **Установка через Shizuku:** `pm install -r <путь>`; процесс MCleaner при этом завершится, новая версия стартует с лаунчера.
- **Без Shizuku:** `PackageInstaller` session + подтверждение пользователя. Если источнику не разрешена установка — открываем экран «Установка неизвестных приложений» для MCleaner.
- **Подлинность:** Android ставит обновление только с тем же ключом подписи, что у установленной версии.
- **Автопроверка:** один раз на запуск активити (не на поворот экрана). Ошибки молча, окно — только если есть новая версия. Кнопка «Позже» закрывает окно до следующего запуска.

## Не делаем
- Фоновую проверку по расписанию, когда приложение закрыто.
- Пропуск отдельной версии («больше не показывать для 1.2.0»).
- Откат на предыдущую версию.
