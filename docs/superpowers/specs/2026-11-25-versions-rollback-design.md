# MCleaner: хранение версий, откат, резервная копия настроек — короткий дизайн

## Решения пользователя
- Перед скачиванием проверять, нет ли этой версии на устройстве; хранить не больше 5 скачанных версий, старые удалять.
- Можно установить предыдущую версию — с GitHub или из скачанных на устройстве.
- Откат на обычной прошивке — с переустановкой после предупреждения.
- Настройки хранятся в файле на устройстве, чтобы переустановка их не сбрасывала.

## Как устроено
- **Папка MCleaner:** `/sdcard/MCleaner/` (вне `Android/data`, переживает удаление приложения). Нужен доступ ко всем файлам — в полном режиме MCleaner выдаёт его себе сам. Без доступа APK хранятся в папке приложения, а копия настроек не пишется.
- **Скачанные версии:** `/sdcard/MCleaner/updates/MCleaner-<версия>.apk`. Перед скачиванием — если файл есть и совпадает размер и SHA-256, повторно не качаем. После скачивания оставляем 5 самых новых, остальные удаляем. Недокачанные `.part` удаляем.
- **Копия настроек:** `/sdcard/MCleaner/settings.json` — белый список, замороженные, автоускорение, остановка Google-сервисов. Пишется после каждого изменения настроек.
- **Восстановление:** при запуске, если настройки ещё ни разу не сохранялись этой установкой (нет отметки `initialized`) и файл есть — берём из файла. Версии до 1.2.0 этого не умеют.
- **Список версий:** все релизы с GitHub (`/releases`) + файлы на устройстве; одна строка на версию с пометками «на устройстве» / «GitHub», текущая — не показывается.
- **Новее текущей:** обычное обновление.
- **Старше текущей — только через Shizuku:**
  - Прошивка отладочная (`ro.debuggable=1`): `pm install -r -d` — поверх, настройки сохраняются.
  - Обычная: копируем старый APK и текущий APK в `/data/local/tmp`, затем отдельным процессом shell (`setsid`, переживает выход MCleaner): `pm uninstall` → `pm install` старой; если установка не удалась — ставим текущую обратно; затем запускаем MCleaner. После переустановки Shizuku попросит разрешение заново.
  - Предупреждение перед откатом: что MCleaner переустановится, вернутся ли настройки (версия ≥ 1.2.0 — да, из копии; старше — нет, но копия останется), что Shizuku спросит разрешение снова.
- Без Shizuku откат недоступен: системный установщик не ставит более старую версию.

## Не делаем
- Откат без Shizuku.
- Хранение копий настроек по версиям (одна актуальная копия).
